# Ferramentas de Inteligência Artificial & Agentes (`tools/ai/`)

Este diretório contém as definições de contexto, diretivas de arquitetura e definições de agentes para auxílio no desenvolvimento da Zennity Engine.

- `tools/ai/ai/`: Contexto do projeto, diretivas de design e especificações arquiteturais.
