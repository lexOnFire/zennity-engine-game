# Editor Legacy (Arquivado / Modo Compatibilidade)

Este diretório contém os módulos do editor Tkinter original da Zennity Engine.

> [!NOTE]
> **Status:** Arquivado para compatibilidade retroativa com testes legados de viewport 2D (`Editor2DScene`).  
> O editor principal e oficial da engine é baseado em Qt e desacoplado na pasta `editor/`, consumindo exclusivamente os serviços oficiais do `engine/`.
