# ADR-005 — Entrypoint Canônico do Editor

**Status:** Aceito • **Data:** 2026-07-19

---

## Contexto

O repositório contém launchers históricos para diferentes experimentos de UI,
incluindo `editor/main.py`, `editor/phase1_main.py`, `premium_main.py`,
`studio_main.py`, `mvp_main.py` e `isolated_editor_main.py`. A documentação já
apontava para mais de um deles. Isso permitia que atalhos, testes e releases
iniciassem shells com comportamento diferente.

## Decisão

O único entrypoint público do editor é:

```bash
python -m editor.phase1_main
```

Quando o projeto estiver instalado como pacote, o alias equivalente é:

```bash
zennity-editor
```

`editor.phase1_main` delega ao editor com viewport isolado. O editor embutido
antigo permanece acessível apenas para diagnóstico temporário por meio de
`--legacy-embedded`. Os outros launchers são internos ou de compatibilidade e
não podem ser referenciados por documentação nova, scripts de release ou
atalhos oficiais.

Esta decisão define a porta de entrada; ela não remove shells nem altera seu
comportamento. A remoção futura exige inventário de consumidores e testes de
caracterização próprios.

## Consequências

**Positivas:**

- documentação, instalação e release passam a apontar para o mesmo bootstrap;
- testes podem congelar um único contrato público;
- shells experimentais deixam de competir como fonte de verdade;
- a consolidação futura pode ocorrer atrás de uma interface estável.

**Negativas:**

- launchers históricos continuam existindo durante a migração;
- automações externas que chamam `editor/main.py` precisam migrar;
- o comando instalado exige as dependências opcionais do editor.

## Alternativas consideradas

- Tornar `editor/main.py` canônico: rejeitado porque ele inicia um shell
  diferente do fluxo Phase 1 atualmente documentado e testado.
- Expor diretamente `isolated_editor_main.py`: rejeitado porque revela um
  detalhe arquitetural que deve poder mudar sem quebrar usuários.
- Remover todos os launchers agora: rejeitado por risco de regressão antes do
  inventário e da cobertura de caracterização.
